# VCS

## Setup

- Main branch: `main`
- Platform: `github` (`Dyloow/task-manager`, public)

## Branches

- Format: `type/short-description`
- Types in use: `feat`, `fix`, `chore`, `docs`, `test`, `refactor`

## Commits

- Convention: conventional commits
- Format: `type(scope): description`
- Rules: imperative mood, lowercase, max 72 chars, English.
- Author is the repo-local git identity. No AI co-author trailer, no mention of an AI tool in commits or PRs.
